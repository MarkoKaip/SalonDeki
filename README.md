# Salon Deki

Moderan web sajt za online zakazivanje termina u frizerskom salonu.

## Instalacija (XAMPP)

1. Pokrenite Apache i MySQL u XAMPP-u.
2. Otvorite u browseru: `http://localhost/frizerski_salon/install.php`
3. Nakon uspešne instalacije obrišite `install.php`.

## Pristup

- **Sajt:** `http://localhost/frizerski_salon/`
- **Admin:** `http://localhost/frizerski_salon/admin/login.php`
- **PIN:** `2109`

## Funkcionalnosti

- Online zakazivanje (usluga, datum, termin, podaci klijenta)
- Kalendar narednih 7 dana
- Sprečavanje duplih rezervacija
- Admin pregled rezervacija po danu/nedelji/mesecu
- Potvrda i otkazivanje rezervacija

## Radno vreme termina

- **Trenutna nedelja:** ut–pet 12:00–19:30, sub–ned 08:00–16:00
- **Sledeća nedelja:** ut–ned 08:00–16:00
- **Ponedeljak:** neradan
- Termini na 30 minuta
